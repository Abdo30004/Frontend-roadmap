# ما الفرق بين Flexbox و CSS Grid ومتى تستخدم كلاً منهما؟

**المستوى:** مبتدئ (Junior)
**Merged from (original phrasings):**
- اشرح نظام Flexbox في CSS.
- اشرح الفرق بين CSS Grid و Flexbox ومتى تستخدم كلاً منهما.

## The concept (short answer)
- **Flexbox** هو نظام تخطيط **أحادي البعد (one-dimensional)**: يرتب العناصر إما في **صف واحد أو في عمود واحد**. وهو نظام **يقوده المحتوى أولاً (content-first)**: تتحدد أحجام العناصر بناءً على محتواها الداخلي، ويقوم Flexbox بتوزيع المساحة المتبقية بينها.
  - الحاوية (Container): `display: flex`، و `flex-direction`، و `justify-content` (للمحور الرئيسي)، و `align-items` (للمحور المتقاطع)، و `flex-wrap`، و `gap`.
  - العناصر (Items): `flex: <grow> <shrink> <basis>` (مثل `flex: 1` لاقتسام المساحة بالتساوي)، و `align-self`، و `order`.
  - قيمة افتراضية هامة: `min-width: auto` على عناصر flex، مما يجعل المحتوى الطويل (كالعناوين الطويلة والجداول) **يرفض الانكماش** ويتجاوز حدود الحاوية. والحل هو ضبط `min-width: 0`.
- **CSS Grid** هو نظام تخطيط **ثنائي الأبعاد (two-dimensional)**: يتحكم في الصفوف **والأعمدة** معاً في نفس الوقت. وهو نظام **يقوده التخطيط أولاً (layout-first)**: تحدد المسارات مسبقاً، وتوضع العناصر بداخلها، فتصطف العناصر بدقة عبر الصفوف والأعمدة.
  - الخصائص: `display: grid`، و `grid-template-columns`، و `grid-template-rows`، و `grid-template-areas`، و `gap`، ووحدات مثل `fr`، والنمط السحري `repeat(auto-fill, minmax(200px, 1fr))` للشبكات المتجاوبة دون الحاجة لاستعلامات الوسائط (media queries).
- **متى تستخدم كل منهما:**
  - Flexbox: أشرطة التنقل (navbars)، مجموعات الأزرار، التوسيط الرأسي والأفقي، صفوف الوسوم (tags)، محاذاة الأيقونة بجانب النص، والمكونات التي تختلف فيها أحجام العناصر بحسب محتواها.
  - Grid: التخطيط العام للصفحة (header/sidebar/main/footer)، معارض البطاقات (card galleries)، لوحات التحكم (dashboards)، النماذج التي تتطلب محاذاة الحقول مع تسمياتها، وأي تصميم يتطلب اصطفافاً دقيقاً في الاتجاهين.
- التكامل بينهما: استخدام Grid للتخطيط العام للصفحة، و Flexbox لتنظيم العناصر داخل كل مكون.

```css
.center { display: flex; justify-content: center; align-items: center; }
.cards  { display: grid; grid-template-columns: repeat(auto-fill, minmax(220px, 1fr)); gap: 16px; }
```

## Real-life example: the problem
تخيّل صفحة لقوائم العقارات. بُنيت بطاقات العقارات باستخدام Flexbox ونسب العرض المئوية. واجه المستخدمون عدة مشكلات: على أجهزة التابلت احتوى **الصف الأخير على بطاقتين ضخمتين ممتدتين بعرض شاذ** بينما احتوت الصفوف السابقة على 3 بطاقات، وكانت البطاقات في نفس الصف ذات **ارتفاعات متفاوتة مما جعل أزرار "Contact agent" غير متناسقة الارتفاع**، كما تسبب عنوان طويل في **دفع الشريط الجانبي خارج الشاشة** على الهواتف وظهور شريط تمرير أفقي مزعج.

```html
<div class="page">
  <aside class="filters">...</aside>
  <section class="listings">
    <article class="card">
      <img src="house.jpg" alt="3-bedroom house" />
      <h3>Very-long-street-name-without-spaces-12345-Springfield</h3>
      <p>$450,000</p>
      <button>Contact agent</button>
    </article>
    <!-- المزيد من البطاقات -->
  </section>
</div>
```

```css
/* BROKEN */
.page { display: flex; }
.filters { width: 250px; }               /* تنكمش عندما تضيق المساحة */
.listings { display: flex; flex-wrap: wrap; }   /* غياب min-width: 0 -> يفيض النص الطويل خارج الشاشة */

.card {
  flex: 1 1 30%;                         /* الصف الأخير: تتمدد البطاقات المتبقية لتملأ كامل الصف */
  margin: 8px;                           /* الهوامش + 30% -> عدد غير متناسق في الصف */
}
/* تستقر الأزرار مباشرة بعد النص، فتظهر بارتفاعات متباينة عشوائية */
```

## How to fix it
استخدم Grid للأجزاء ثنائية الأبعاد (تخطيط الصفحة ومعرض البطاقات)، واستخدم Flexbox داخل كل بطاقة لدفع الزر إلى الأسفل دائماً.

```css
/* FIXED */
.page {
  display: grid;
  grid-template-columns: 250px minmax(0, 1fr); /* الشريط الجانبي ثابت، والمحتوى الرئيسي يقبل الانكماش */
  gap: 24px;
}

@media (max-width: 768px) {
  .page { grid-template-columns: 1fr; }        /* جعلها في عمود واحد على الهواتف */
}

.listings {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(240px, 1fr)); /* أكبر عدد ممكن من البطاقات المتساوية */
  gap: 16px;                                   /* استخدام gap بدلاً من الهوامش */
}

.card {
  display: flex;
  flex-direction: column;                      /* أحادي البعد: عمود رأسي */
  min-width: 0;                                /* السماح بالانكماش دون فرض عرض المحتوى */
}

.card h3 {
  overflow-wrap: anywhere;                     /* كسر الكلمات الطويلة جداً */
}

.card button {
  margin-top: auto;                            /* دفع الزر إلى أسفل البطاقة بمحاذاة تامة */
}
```

لماذا ينجح هذا الحل:
- تُنشئ الصيغة `repeat(auto-fill, minmax(240px, 1fr))` أكبر عدد ممكن من الأعمدة المتساوية. وتحتفظ كل بطاقة في الصف الأخير بنفس عرض باقي البطاقات تماماً، لأن أعمدة Grid تحددها الحاوية وليس حجم العناصر.
- تتمدد عناصر Grid في نفس الصف إلى نفس الارتفاع افتراضياً، ويقوم عمود flex الداخلي مع `margin-top: auto` بتثبيت جميع الأزرار عند قاع البطاقة، فتصطف في خط أفقي مستقيم.
- تمنع خصائص `minmax(0, 1fr)` و `min-width: 0` و `overflow-wrap` المحتوى الطويل من إجبار التخطيط على التمدد خارج عرض الشاشة.
- تحل خاصية `gap` محل الهوامش وتغني عن العمليات الحسابية المعقدة بالنسب المئوية.

بدائل إضافية: خاصية `auto-fit` بدلاً من `auto-fill` تمدد البطاقات لملء الصف عند قلة عددها؛ كما يمكن لـ `subgrid` محاذاة العناوين والأسعار والأزرار أفقياً عبر البطاقات المتجاورة.

## How to say it in the interview
- "Flexbox أحادي البعد ويقوده المحتوى: ممتاز لمحاذاة العناصر في صف أو عمود. بينما Grid ثنائي الأبعاد ويقوده التخطيط: ممتاز عندما يجب اصطفاف العناصر أفقياً ورأسياً في آن واحد."
- "أستخدم Grid عادةً لتخطيط الصفحة العام ومعارض البطاقات، و Flexbox داخل المكونات نفسها مثل أشرطة التنقل ومجموعات الأزرار ومحتوى البطاقة."
- فخ المقابلة: القيمة الافتراضية `min-width: auto` لعنصر flex تسبب فيضان النصوص الطويلة؛ وضبط `min-width: 0` (أو `minmax(0, 1fr)` في Grid) يصلحها فوراً.
- المفاضلة: لا يستطيع Flexbox محاذاة العناصر بين الصفوف المتعددة عند الالتفاف (wrapping)؛ بينما يتقن Grid ذلك. لكن Grid يحتاج هيكلية مسبقة، لذا للصفوف البسيطة ذات المحتوى المتغير يكون Flexbox أسهل وأكثر رشاقة. وكلاهما يدعم `gap`.
